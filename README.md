# 🚀 Let’sTalk – Real-Time Distributed Chat System

🚧 This project is currently under active development.

## 📌 Overview
Let’sTalk is a scalable, high-performance real-time chat system built using Golang. It is designed with modern backend architecture principles including WebSockets, gRPC, Kafka, and PostgreSQL.

## 🧠 Goal
The goal of this project is to build a production-grade distributed chat system capable of handling real-time communication at scale.

## ⚙️ Tech Stack (Planned)
- Golang
- WebSockets
- gRPC
- Apache Kafka
- PostgreSQL
- Docker & Kubernetes

## 🚧 Status
Initial project setup and base structure created.  
WebSocket implementation is currently in progress.
